# CDspectrometer

A low-cost, portable circular dichroism (CD) spectrometer for measuring plasmonic chiral nanoparticles, built using a tungsten light source and a handheld CCD photospectrometer.

## Overview

Commercial CD spectrometers are dominated by a small number of manufacturers, making the technique costly and largely inaccessible to smaller laboratories, educational institutions, or field-based research. This project provides an open-source, low-cost, and easy-to-build alternative designed for daily benchtop use.

Rather than competing with the performance of high-end commercial instruments used for molecular chirality in biological systems, this design is focused on plasmonic chiral particles, prioritizing compactness, affordability, and ease of manufacturing and use.
